# sams_kitchen_app

Full-stack restaurant ordering app for Sam's Kitchen with noodles dinner specials, Indian appetizers, Italian mains, secure auth, and Stripe payments

## Tech Stack

- **Backend:** Express.js + TypeScript + Prisma ORM
- **Frontend:** React + TypeScript + Vite
- **Database:** SQLite (dev) / PostgreSQL (prod)
- **Auth:** JWT (JSON Web Tokens)

## Quick Start

```bash
# Backend
cd backend
npm install
npx prisma generate
npx prisma db push
npx tsx prisma/seed.ts
npx tsx src/index.ts

# Frontend (separate terminal)
cd frontend
npm install
npm run dev
```

## Deploy on Railway

1. In Railway, create a project from this GitHub repository.
2. Add a PostgreSQL database to the project (Railway's Postgres template). Railway names the service `Postgres`.
3. In your app service's **Variables**, set:
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}` (Railway fills in the database's address)
   - `JWT_SECRET` = a long random string
   - `NODE_ENV` = `production`
   - `SERVE_FRONTEND` = `1` (the backend serves the built frontend)
4. Deploy. Railway sets `PORT` itself.
